# Mass Effect – Art

> 🗄️ **Archived learning project.** Built in 2017 while taking an introductory iOS course, kept as-is as a snapshot of where I started. It targets Swift 3 / iOS 10 and won't build in current Xcode without migration.

Planned as a small gallery app for Mass Effect artwork. It never got past the Xcode project template, so this repo is a placeholder for an idea from May 2017.

**Stack:** Swift 3 · UIKit · iOS 10.3 (template only)
